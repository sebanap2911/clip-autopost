Clip Autopost

A personal, non-commercial publishing tool

Clip Autopost is a private desktop tool used by a single content creator. It cuts short vertical clips (9:16) from the creator's own long gameplay videos and publishes the selected clips to the creator's own accounts on TikTok and YouTube Shorts at scheduled times.

How it works

  1. The creator signs in once with their own TikTok and YouTube accounts using the official login pages (TikTok Login Kit and Google OAuth).
  2. The creator chooses which finished clips to publish and when.
  3. The tool uploads each clip with its title and description through the official TikTok Content Posting API and the YouTube Data API.

The tool runs only on the creator's own computer. It has no other users, no public sign-up and no server that stores user data.
