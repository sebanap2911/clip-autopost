Privacy Policy

Last updated: November 21, 2026

Clip Autopost ("the tool") is a personal desktop tool that publishes the operator's own video clips to the operator's own TikTok and YouTube accounts. This policy explains what data the tool accesses and how it is handled.

1. Data the tool accesses

  • TikTok: basic profile information (open ID, display name and username, scope user.info.basic), the account's posting options returned by the Content Posting API (allowed privacy levels, maximum video length, comment/duet/stitch settings), and permission to publish videos (scope video.publish).
  • YouTube: permission to upload videos to the connected channel (scope youtube.upload). The tool does not read other channel data.
  • Access tokens issued by TikTok and Google after sign-in.

2. How the data is used

The data is used only to publish the clips selected by the operator, with the chosen title, description and privacy settings, and to check whether each upload succeeded. It is not used for advertising, profiling, analytics or any other purpose.

3. Storage

Access tokens and upload results (video IDs, post links, status) are stored only in local files on the operator's own computer. The tool has no server and no database. No data is sold, shared with or transferred to third parties, other than sending the videos and their texts to TikTok and YouTube as requested by the operator.

4. Retention and deletion

Data is kept until the operator deletes the local files. Access can be revoked at any time in TikTok settings (Security and permissions → Manage app permissions) or on Google Account permissions; revoked tokens stop working immediately.

5. Google API Services

The tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The tool uses YouTube API Services; see also the Google Privacy Policy.

6. Children

The tool is not directed at children and is used only by its adult operator.

7. Changes and contact

This policy may be updated; the date at the top shows the latest version. Questions can be sent through the GitHub repository that hosts this website (Issues tab).
